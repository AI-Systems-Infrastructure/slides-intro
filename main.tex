\section{Why This Course}

\begin{frame}{What is AI made of?}
\begin{columns}[c]
    \begin{column}{0.6\textwidth}
        Previous semesters and the Deep Learning course give us \textit{part of the answer}.
        \begin{itemize}
            \item \textbf{AI models}, usually neural networks trained on large amounts of data
            \item Implemented mostly in Python, with libraries like PyTorch, JAX, and TensorFlow
            \item Essentially a type of software
        \end{itemize}

        \vspace{0.5em}
        However, \emphasis{AI models alone cannot serve millions of people around the globe}.
    \end{column}
    \begin{column}{0.38\textwidth}
        \centering
        \includegraphics[width=\linewidth,height=0.78\textheight,keepaspectratio]{intro-model-and-code}
    \end{column}
\end{columns}
\note{
}
\end{frame}


\begin{frame}{What is missing around the model?}
\begin{columns}[c]
    \begin{column}{0.56\textwidth}
        To put AI into every corner of the digital world, \textit{AI models need to talk to all kinds of software}.
        \begin{itemize}
            \item Search engines, messaging apps, code editors, smartphone operating systems
            \item Most of them are not written in Python
            \item Even Python software is rarely one giant project where everything can just call each other
        \end{itemize}

        \vspace{0.5em}
        How do we let AI models and the rest of the digital world \emphasis{communicate in a standardized, language-agnostic way}?
    \end{column}
    \begin{column}{0.42\textwidth}
        \centering
        \includegraphics[width=\linewidth,height=0.78\textheight,keepaspectratio]{intro-model-in-software}
    \end{column}
\end{columns}
\note{
}
\end{frame}


\begin{frame}{Why can't I just run it on my laptop?}
  \textbf{Top AI models} from OpenAI, Anthropic, Google, etc. run in \textit{data centers}, each drawing the power of a small town.
    \begin{itemize}
        \item Why don't they fit on your laptop or smartphone?
        \item How do these companies manage tens of thousands of machines?
        \item Can you run a useful AI model at home, on your own hardware?
    \end{itemize}

    \vspace{0.5em}
    What kind of \emphasis{infrastructure and deployment techniques} make all of this possible?

    \vspace{0.5em}
    \begin{center}
        \includegraphics[width=0.7\textwidth,height=0.34\textheight,keepaspectratio]{lumi}
    \end{center}
\note{
}
\end{frame}


\begin{frame}{What this course is about}
    The goal of this course is to answer these questions.

    \vspace{0.5em}
    \begin{block}{Prerequisites}
        \begin{itemize}
            \item Basic Python skills, covered in \textit{DAKI1 AI Programming}
            \item Understanding of AI models, covered in \textit{DAKI2 AI and Data} and \textit{DAKI3 Deep Learning}
        \end{itemize}
    \end{block}

    \begin{block}{The angle}
        AI models are only part of an AI system.
        \textit{Everything around the models} is what makes them usable at scale.
    \end{block}

    \begin{block}{The outcome}
      Learn \textit{industry-standard techniques} to replicate what AI companies do: \emphasis{Implementing and deploying AI systems at scale}.
    \end{block}
\note{
}
\end{frame}

    Done after the lecture, with goals and tips at the end of each blog post.

    \begin{itemize}
      \item Aim to solve a practical problem with the knowledge learned in each module
      \item Usually built on top of exericses of previous modules
      \item Foundation for the mini project
    \end{itemize}
  \end{block}

  \begin{block}{Lectures}
    30 to 60 minutes each. An inspirational walkthrough of the module.
